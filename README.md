# Junaid Ali Khan — QA Portfolio

A responsive, dark-theme, single-page portfolio presenting QA leadership, FinTech/RegTech quality engineering, test automation projects, identity and biometric verification testing, Android/iOS application testing, investment workflow QA, streaming app testing, and LLM response evaluation.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `junaid-qa-portfolio`.
2. Upload the contents of this folder to the repository root (make sure `index.html` is at the root).
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.
