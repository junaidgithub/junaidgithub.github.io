BUG-001 — Phase 0: exact duplicate rows not removed  Critical

The raw file has 28 rows where all five source fields are identical. Per the SOP, only fully identical rows are de-duplicated, so Phase 0 should hold 7,735 unique records but ingests 7,763. Fix: de-duplicate the raw file before the pipeline runs.

BUG-002 — Phases 2 & 3: denotified records given the NI prefix instead of DE  Critical · recurring, growing

77 denotified records are labelled with the proscribed-individual prefix, so the client bank's screening system would show them as proscribed instead of denotified. The count has grown across runs. Fix: re-run Record ID assignment with the DE prefix and regenerate Phase 2 and Phase 3.

BUG-003 — Phase 1: nationality stored as ISO code  Critical

The SOP requires Nationality = ['Pakistan'] when a national ID is present. The pipeline writes ['pk'] for all 6,294 such records, and the value is copied unchanged into Phase 2 (Nationality) and Phase 3 (NTL). Records without an ID correctly hold an empty list. Fix: resolve the ISO code to the country name before writing Phase 1.
